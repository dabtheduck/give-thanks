# Give Thanks — Visuals (one-page board)
Rougher cozy pixel, for everyone. No cute-only, no pastel-only.

## Palette (use these exact hexes)
- Cream background: #FFF6E5
- Charcoal ink / borders: #2B2B2B
- Forest green (primary button, plant): #4A7C59
- Sage (secondary, garden): #A8C3A0
- Burnt orange (accent): #D97B29
- Burnt sienna (Share accent): #A0522D
- Stone grey (muted text, blurred blocks): #8A8A8A
- Wood brown (frames, garden soil): #7A5230

Rule: cream + charcoal everywhere, forest for the main action, burnt sienna for Share. No red, no pink as a main colour.

## Type
- Headings / big count: monospace pixel feel — “Press Start 2P” on web, fallback Courier New. Big count 84px, headings 20-24px.
- Body / notes: system sans, 15px, readable. Notes must never be in pixel font — they are personal text.
- Buttons: uppercase, pixel font, 18-24px.

## Counter screen (first screen)
- Top: “🌱 GIVE THANKS” left, date right, 4px charcoal rule under.
- Centre: plant emoji that grows 🌱 → 🌿 → 🌷 → 🌻 → 🌳 as count rises, no target number.
- Huge count, then big forest button: “+ THANKS”, 4px border, 6px hard shadow, pops 120ms on press.
- Under it: note input + “Add note” in orange, then today's notes list, each with a small “share” checkbox.
- Bottom tabs: Counter / Garden / Science / Settings. No feed, no badges.

## Press feel (addictive, calm)
- 120ms pop, tiny pixel sparkle, soft pop sound (mutable), light haptic on mobile.
- No combo timer, no flashing, no “keep going!” copy.

## Garden
- Pixel field on sage background, flowers as 🌸 / pixel plants, no names, no counts per person.
- Group garden: same field, title is the group name, nothing else changes.

## Share card (art page)
- 1080×1350 PNG, cream background, charcoal 16px top/bottom bars.
- Title “🌱 GIVE THANKS”, date, huge count, then notes in monospace.
- Shared notes: charcoal text. Private notes: grey pixel block, same width, no text leaked.
- Footer in burnt sienna: “made with Give Thanks”.

## About / Bulletin Board
- Same cream / charcoal, headings in pixel font, body in sans, short sections, lots of whitespace.
